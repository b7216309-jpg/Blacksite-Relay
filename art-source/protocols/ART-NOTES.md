# Blacksite protocol artwork

Three original backplates extend the existing underground relay into physical device close-ups: an exposed copper reactor calibrator, a worn CRT injection terminal and an opened server patch bay. They share dark petrol metal, amber practical lamps, copper wiring and restrained teal reflections. The original relay room, residents, lighting, shadows, intro and music are retained.

The selected PNGs are unchanged copies of built-in ImageGen outputs. `selected-assets.json` records dimensions, hashes and source filenames. `prompts/device-backplates.json` contains the complete generation prompts. The Memory opening required one targeted ImageGen correction, recorded in `prompts/memory-recess-revision.txt`, so the existing 275 x 275 interactive grid would fit without shrinking its cells.

Every command, timer, readout, target and cell is rendered separately by the game. The artwork contains no painted interface text or target markers. The final layout follows the actual clear spaces in the selected images rather than covering their hardware with generic panels. Injection groups its target, input and clock inside the CRT glass; Bypass groups its readouts and scanner below the exposed coil. Memory retains its 30-pixel cells and 5-pixel gaps.

The backplates use a fixed 420 x 650 display and pixelated image sampling. A restrained edge scrim supports headings and footer controls. The image layer cannot receive input. A missing image leaves the native controls on a dark fallback surface. In 1.3.1, a separate native canvas adds lamps, surface modulation and brief contact sparks to the hardware. The original PNG and active challenge layout stay registered; the main relay room remains paused during protocols. Active input permits subdued hardware lights, while preparation/results allow contact sparks and copper-path pulses. Bypass retains immediate access and acknowledges a successful stop with a tiny contact spark without changing its scanner. See animation/ROOT-REVIEW.md and animation/README.md for the current visual review and authoring workflow.

Native composition, phase, keyboard, scaling and lifecycle checks are documented in the release verification notes. The original generation sources are included in Generated-Art.zip and the editable-art archive; the rejected narrow Memory draft is omitted from delivery.
